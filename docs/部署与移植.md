# 部署与移植（MockController）

完整清单见 Runner 工程：`D:\ATE\MockRunner\docs\部署与移植.md`。本文只记 Controller 侧要点。

## 目标机要求

- Windows 10/11 x64
- Python 3.10~3.13（64 位），在 PATH 或设置 `ATE_PYTHON`
- Microsoft Edge（`tools/open_ui.ps1` 自动探测）
- 不需要 Node.js：`controller-web/web_dist/` 已随仓库提交

## 启动

```bat
start_controller.bat
```

解释器顺序：`ATE_PYTHON` → 本工程 `.venv` → 同级 `MockRunner\backend\.venv` → PATH → 尝试创建 `.venv`。
依赖缺失时自动装；存在 `wheels\` 时走 `pip --no-index --find-links wheels`。

## 目录与变量

| 项 | 默认 | 覆盖 |
| --- | --- | --- |
| 数据根 | 工程内 `repo/` | `MOCK_CONTROLLER_REPO` |
| 端口 | 8070 | 修改 `start_controller.bat` 的 `PORT` |
| 解释器 | 自动探测 | `ATE_PYTHON` / `MOCK_CONTROLLER_PYTHON` |
| Assistant 货架 | 同级 `MockRunner\backend\assistant_shelf` | `ATE_ASSISTANT_SHELF` |

## 换机不要拷

`.venv/`、`__pycache__/`、`.pytest_cache/`、`.pytest_tmp*/`、`controller-web/node_modules/`。
`repo/` 只在需要保留历史数据时迁移。

## 自检

```powershell
curl http://127.0.0.1:8070/api/v1/health
```

浏览器打开 `http://127.0.0.1:8070/ui/`，确认页面加载、机器常数与 TPS 清单可读。
